The algorithms stay in the packages; this plugin is glue. Both packages are bundled inside the plugin, so they need no download; numba, rasterio and fiona are installed into QGIS's Python on first run.

changelog=0.5.0 -- you choose which band is which. Colour conversion takes explicit red, green and blue band numbers instead of assuming 1/2/3, which was wrong for every CIR and NRGB raster; the segmentations take an optional band selection, empty meaning all. Bundles pygeoadaptels 0.10.1, which vectorises to GeoPackage about twelve times faster.
    0.4.3 -- the compute kernels are compiled on the main thread before the run starts. Installing the plugin from a zip wipes numba's compiled cache, and recompiling it on the worker thread took QGIS down; the first run after an update now pauses briefly instead.
    0.4.2 -- fixed a crash when styling the result of a large segmentation: the label-count check scanned every pixel on the GUI thread while the task was closing down. Styling now decides from the raster size, and never attaches itself to an output QGIS is not loading.
    0.4.1 -- plugin icon in the Plugin Manager, provider named GeoAdaptels + GeoPalette, metadata points at the plugin's own repository.
    0.4.0 -- renamed to match the renamed packages; packages bundled in the zip.
    0.3.0 -- the two pure-Python packages ship inside the plugin: no git, no download for them.
    0.2.2 -- label rasters get contrasting colours instead of an all-black palette.
    0.2.1 -- fixed a phantom output that made QGIS report a missing layer.
    0.2.0 -- styled results, advanced parameters collapsed, help with the dead-tree recipe.
    0.1.1 -- dependency bootstrap resolves QGIS's real interpreter.
    0.1.0 -- first release: six algorithms in the Processing toolbox.
